# MiniSniffer

MiniSniffer es un sniffer de red básico desarrollado en Python usando la librería Scapy. Su función principal es capturar paquetes de red IP y mostrar información relevante como la dirección origen, la dirección destino, el protocolo y el tamaño del paquete.

El proyecto incluye una interfaz gráfica simple con Tkinter para iniciar la captura y visualizar los paquetes en tiempo real.

## Descripción del proyecto

Este proyecto permite:

- capturar paquetes de red
- filtrar paquetes que contienen capa IP
- mostrar información esencial de cada paquete
- ejecutar la aplicación desde una interfaz gráfica

## Tecnologías utilizadas

- Python 3
- Scapy
- Tkinter
